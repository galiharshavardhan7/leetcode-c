# LeetCode Solutions in C

I mainly focused on C and C++ starting out, and I'm using this repo to track my journey through Data Structures & Algorithms as I solve LeetCode problems — keeping things organised so I can look back and see how I've improved (and revisit problems when I forget how I solved them the first time).

C isn't the most common language for LeetCode, but I picked it because it forces me to actually understand what's happening under the hood — memory management, pointers, no built-in shortcuts to hide behind.
